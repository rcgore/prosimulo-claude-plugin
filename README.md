# ProSimulo AI Data for Claude

ProSimulo AI Data helps users save, organize, and retrieve selected information from their AI conversations. It is a separate system of record for user-managed Items, Records, and supporting materials. The Claude plugin connects to an existing ProSimulo account through ProSimulo's remote MCP service.

## Getting started

Install the ProSimulo AI Data plugin in Claude. In the plugin's **Connectors** tab, connect the ProSimulo connector, sign in to your ProSimulo account, and authorize the connection. Installing the plugin alone does not complete account authorization.

You can then ask Claude to find information in ProSimulo or prepare a new Record. Saving changes uses a review and explicit confirmation step. An action is not complete merely because Claude has proposed it. Access depends on your account permissions and any Record-level AI restrictions.

## Data handling

ProSimulo processes information you explicitly direct the integration to save or retrieve, together with data needed for account authentication, storage, and service operation. Information returned to Claude can also be processed by Anthropic under its own terms. This plugin does not automatically import Claude conversation history or files.
